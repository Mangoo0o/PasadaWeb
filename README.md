# PasadaWeb

PasadaGuide Web Application & Admin Management Suite for Bauang Municipality Tricycle Transportation.

## Features
- **Passenger Booking & Live Map**: Interactive Leaflet maps with live driver tracking and regulated location pricing.
- **Location-Based Tariff System**: Dynamic pricing per preset destination locations with proximity-based matching engine.
- **Admin Management Suite**:
  - Live Dispatch & Driver Fleet Monitoring
  - Terminal Operations & Driver Management
  - Location Tariff & Fare Matrix Manager with Leaflet map testing suite
  - Compliance & Audit Trail Logging
- **Real-Time Engine**: Built on Supabase Realtime Channels for instant driver tracking and booking dispatch.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
